隱私權政策

最後更新：2026 年 11 月 26 日

一句話版本：你的飲食、體重、運動和記帳資料只存在你自己的裝置上，我們看不到，也沒有收集。

1. 存在你裝置上的資料

你在 NutriMate 輸入的所有記錄（飲食、喝水、體重、運動、訓練、記帳、個人設定）都只儲存在你的瀏覽器／手機本機，不會上傳到我們的伺服器。這也表示：

  • 刪除 App 圖示或清除瀏覽器資料時，記錄會一起消失，我們無法幫你找回。請定期到「設定 → 資料備份」匯出備份。
  • 備份檔由你自己保管。備份檔不包含你的 Gemini API 金鑰與 Pro 序號。

2. AI 拍照辨識（Google Gemini）

使用 AI 拍照辨識時，照片會直接從你的裝置傳送到 Google Gemini API 進行分析，使用的是你自己申請的 API 金鑰。這段傳輸不經過我們的伺服器。照片的處理方式適用 Google Gemini API 條款；使用免費方案時，Google 可能會用這些內容改善服務。請不要拍到臉孔、證件或其他個人資料。

3. 食物搜尋

搜尋食物時，若內建資料庫找不到，App 可能會把你輸入的關鍵字送到 Open Food Facts 公開資料庫查詢。只會傳送搜尋文字。

4. Pro 授權與推播（我們的伺服器）

只有在你啟用 Pro 或開啟背景推播時，App 才會連到我們架在 Cloudflare 上的伺服器，而且只傳送運作需要的最少資料：

  • 啟用 Pro：序號（伺服器只保存經過雜湊處理的版本）、一組隨機產生的裝置代碼、裝置類型（例如「iPhone」）。這些資料用來防止序號被濫用，並限制可啟用的裝置數量。
  • 背景推播：瀏覽器產生的推播訂閱資訊、你設定的提醒時間和時區。關閉提醒或解除裝置後就會刪除。
  • 為了防止濫用，伺服器會短暫記錄連線 IP 來限制嘗試次數，不會長期保存。

付款由 Gumroad 處理，我們不會看到你的信用卡資料。Gumroad 會依其 隱私權政策 提供我們你的 Email 和訂單資訊，用於寄送序號、售後服務與退款。

5. 我們不做的事

  • 不使用廣告追蹤、不使用分析工具、不販售任何資料。
  • 不會讀取你的飲食或健康記錄。

6. 診斷資訊

「設定 → 問題回報」裡的「複製診斷資訊」只會在你主動按下時產生，內容包含 App 版本、裝置型號、錯誤訊息和各類資料的筆數，不包含記錄內容、金鑰或序號。只有你自己貼給我們時，我們才看得到。

7. 聯絡我們

有任何隱私問題，或想刪除伺服器上與你序號相關的資料，請來信：（請見 App「設定 → 問題回報」）
