📸 3 分鐘取得免費 AI 金鑰

AI 拍照辨識使用 Google 的 Gemini。你只要申請一把免費的「API 金鑰」貼進 App，不需要信用卡。

  1. 打開 Google AI Studio 用手機或電腦都可以，登入你的 Google 帳號。
    前往 aistudio.google.com →
  2. 第一次使用會看到同意條款 勾選同意後按「繼續」。如果跳出問卷，可以直接略過。
  3. 建立 API 金鑰 找到「Get API key」或「API 金鑰」頁面，按 Create API key（建立 API 金鑰）。如果要你選擇專案，選預設的或新建一個就可以。
  4. 複製金鑰 畫面會出現一串以 AQ. 開頭的文字（舊的金鑰是 AIza 開頭，兩種都能用），按旁邊的複製按鈕。
    ⚠️ 這串金鑰就像密碼，不要傳給別人。
  5. 貼到 NutriMate 回到 App →「設定」→「🤖 AI 拍照辨識設定」→ 貼上 → 按「儲存金鑰」，再按「測試金鑰」。看到 ✅ 就完成了！
真的免費嗎？是的。Google 提供每日免費額度，一般人一天拍幾餐完全夠用。額度用完時 App 會提示，隔天會自動恢復。只要你沒有自己去設定付費方案，就不會被收費。
測試時出現「金鑰無效」通常是複製時多了空白或少了字。請回到 AI Studio 重新按複製按鈕再貼一次。
出現「地區無法使用」少數國家或地區不提供 Gemini 免費 API，這時就無法使用 AI 辨識，其他功能不受影響。
出現「免費額度用完了」等幾分鐘再試；如果一整天都不行，可能是當天額度用完，隔天就會恢復。
照片會被誰看到？照片會直接從你的手機傳到 Google 分析，不會經過 NutriMate 的伺服器。使用免費方案時，Google 可能會用這些內容改善服務，所以請只拍食物。
換手機了怎麼辦？在新手機重新貼上同一把金鑰就可以，也可以再建立一把新的。
